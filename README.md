# El Reflejo

Primera experiencia estática de autoconocimiento de Toni Real.

## Qué incluye

- Pentáculo interactivo de cinco dimensiones: Espíritu, Aire, Agua, Fuego y Tierra.
- Respuestas que permanecen únicamente en la pestaña.
- Resumen literal y descarga en formato `.txt`.
- Pausa de un minuto, sin ritmo respiratorio impuesto.
- Sin cuentas, IA, pagos, analítica ni envío de textos a servidores.

## Desarrollo

No requiere dependencias. Basta con abrir `index.html` o servir esta carpeta con cualquier servidor web estático.

## Privacidad

Las reflexiones no salen de la pestaña y se pierden al recargar o cerrar. La descarga permite conservarlas de forma local.
